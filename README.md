# GPS Puzzeltocht – proefversie gesproken begeleiding

Dit is een afzonderlijke testomgeving voor de proefversie met gesproken aanwijzingen en gesproken locatie-informatie.

- Testwebsite: https://leeuw008-nl.github.io/GPS-Puzzeltocht-proef/
- De proefversie gebruikt de Nederlandse spraaksynthese van de browser.
- De productiewebsite https://gps-puzzeltocht.leeuw008.nl/ wordt door deze repository niet gewijzigd.

Test bij voorkeur op een smartphone met geluid ingeschakeld.
